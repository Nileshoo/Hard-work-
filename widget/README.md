# SupportAI Widget

Embed the chat widget on any website by adding this script tag:

```html
<script
  src="https://your-cdn.com/widget.js"
  data-business-id="YOUR_BUSINESS_ID"
  data-api-base="https://api.yourdomain.com"
></script>
```

The widget calls the `/api/chat/message` endpoint on your backend to fetch AI answers.
